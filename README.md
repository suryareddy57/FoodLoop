# 🍲 FoodLoop

FoodLoop is a full-stack web application designed to bridge the gap between food surplus and community need. It coordinates surplus food donations efficiently among restaurants, NGOs, receivers, and administrators to reduce food waste and combat hunger.

---

## 🚀 Key Features

* Role-Based Workflows: Tailored dashboards and experiences for Restaurants, NGOs, and Administrators.
* Smart Status Tracking:** A multi-stage food status workflow to track donations from listing to final delivery.
* Visual Urgency Badges:** Time-sensitive countdowns to highlight expiring food items and prioritize rescues.
* Sustainability Calculator:** Real-time metrics showing total meals provided and carbon emissions ($\text{CO}_2$) saved.
* Location Mapping:** Integrated mapping tools to find and coordinate pickups seamlessly.

---

## 🛠️ Tech Stack

* Backend: Java, Spring Boot, Spring Data JPA
* Frontend: JavaScript, HTML5, CSS3, Bootstrap
* Database: MongoDB / Relational Database (configured via `application.properties`)
* Version Control: Git & GitHub
